# 条子计时器 (camptime_tool)

> GW2 战场《监管员 · 义愤填膺》技能剩余时间 OCR 自动倒计时工具，仅限中文

基于 **AutoHotkey v2** 的桌面小工具：按下热键，自动截取游戏画面指定区域，通过本地 OCR 识别"剩余时间"文本，并在屏幕顶部进行秒级倒计时。倒计时结束自动激活游戏窗口提醒。

## ✨ 功能特性

- 🖱️ **一键识别**：鼠标指向技能图标，按下热键即自动 OCR 剩余时间
- 🔢 **秒级倒计时**：识别成功后屏幕顶部实时递减
- 🎹 **自定义热键**：GUI 内点按组合键修改，保存后**立即生效**，无需重启
- 🔒 **防误触锁定**：设置界面处于激活状态时热键自动失效
- 📝 **本地 OCR**：基于 RapidOcr（PP-OCR），全程离线，无网络请求
- ⚙️ **配置持久化**：热键保存于 `orc\config.ini`，重启自动加载

## 📦 环境要求

| 依赖 | 说明 |
|---|---|
| Windows | Win 10/11 x64 |
| AutoHotkey v2 | ≥ 2.0 (AutoHotkey64.exe) |
| RapidOcr.ahk | 本地 OCR 封装（含 `RapidOcrOnnx.dll`） |
| ImagePut.ahk | 屏幕截图库 |
| 游戏 | 激战2 GW2（中文客户端），需在窗口/全屏模式下运行 |

> 游戏内技能名提示文本须为中文（"剩余时间 X分钟 Y秒"）。

## 🚀 快速开始

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/)
2. 确保目录完整（含 `64bit\`、`models\`、两个 `.ahk` 依赖）
3. 双击 `camptime_tool.ahk` 运行
4. 进入 GW2 战场 → 将鼠标移动到"监管员 · 义愤填膺"图标附近
5. 按默认热键 **F8** → 自动识别并开始倒计时

## 🎹 热键

| 热键 | 功能 | 说明 |
|---|---|---|
| `F8`（默认） | 截屏识别 + 开始倒计时 | 可在设置界面自定义 |
| `ESC` | 停止倒计时 | 清除屏幕 ToolTip |
| `F9` / GUI 退出按钮 | 退出软件 | — |

## 🛠️ 自定义热键

1. 点击 GUI 中"启动热键"输入框
2. 直接按下想要的组合键（如 `^F1` = Ctrl+F1）
3. 点击 **保存热键** → 立即生效并写入 `orc\config.ini`

> ⚠️ 设置界面激活时热键被锁定（防误触）；保存后切换到游戏窗口即可使用。

## ⚙️ 工作原理

```
按下热键
   │
   ▼
[截取屏幕区域]      x=窗口左+40%宽，y=窗口顶，宽=高=3×(鼠标Y−窗口顶),基于鼠标所在坐标，想周围扩散，并对区域截图。
   │
   ▼
[RapidOcr 本地识别] 匹配 "剩余时间 (\d+)分钟 (\d+)秒"
   │
   ▼
[换算总秒数 + 定时器] SetTimer 每秒递减
   │
   ▼
[ToolTip 显示剩余秒] 屏幕顶部居中
   │
   ▼
[倒计时归零]       激活 GW2 窗口提醒
```

**截图区域说明**：截图范围以当前**活动窗口**为基准，宽度/高度随鼠标到窗口顶部的距离自动变化（约 3 倍）。如需调整，修改 `DoCapture()` 中 `w := (mousey - y) * 3` 的系数。

## 🔧 配置

`orc\config.ini`（首次运行保存热键后自动生成）:

```ini
[Settings]
Hotkey=F8
```

## ❓ 常见问题

**Q: 提示"未识别到有效时间！"**
- 确认游戏为中文客户端，且"剩余时间"文本在截图区域内
- 鼠标位置需要与技能图标保持合适距离（截图区域跟随鼠标）
- 窗口尺寸/分辨率变化后，尝试调整截图系数

**Q: 保存热键后无法使用**
- 设置界面激活时热键被锁定，切回游戏窗口即可
- 新热键可能被其他程序占用，可换一个组合键

**Q: 倒计时结束后没反应**
- 确认 GW2 进程名为 `Gw2-64.exe`
